# Traces of the White Soul

A 2D action platformer set in a fantasy medieval kingdom. Players follow Axie, a half-human, half-hound character who can switch between two forms while facing enemies and boss encounters across three levels.

## My Contributions

- **QA lead:** Tested levels, enemies, and bosses using unit, integration, and black-box testing.
- **Level design:** Suggested puzzle ideas, enemy placement, and level layouts across the three levels.
- **Saving system:** Implemented save/load with Unity PlayerPrefs, storing player position and soul amount.
- **Voice coordination:** Coordinated voice actors for the player character, boss, and NPCs.
